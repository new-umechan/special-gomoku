# 超能力五目並べ

碁石に超能力がある五目並べ。超能力を駆使して五目並べろ！

1台を2人で囲んで遊ぶ「2人で対戦」、CPU（白）と遊ぶ「CPUと対戦」、知らない人と当たる「オンライン対戦」がある。

- 始める前にデッキを選ぶ。スターターデッキ（バランス・物量・すっぱいスパイ・一発逆転）か、自分で作ったデッキ。2人で対戦では、黒と白が横に並んで選ぶ
- デッキは「デッキを作る」画面で作る（選ぶ画面の＋や鉛筆、または上の「デッキ」から）。24ポイントの中で組み、ただの石は1ポイント、強い碁石ほど高い（2〜6ポイント）。同じ超能力は3つまで。作ったデッキはいくつでもブラウザに保存できる
- 強い碁石ばかりだと、置ける数が減る。数と強さのどちらを取るかを選ぶ
- 5つ並べるほか、旗による特殊勝利がある
- 超能力の碁石は31種類
- 手札3つから1つ選んで置く。5つ並べたら勝ち。2人とも使い切って揃わなければ引き分け

## 超能力
| 名前 | ポイント | 効果 |
|---|---|---|
| ジョーカー | 2 | 白にも黒にもなる。相手の列にも入る |
| 押し出し | 2 | まわりの石を1マス外へ押す。盤から落ちた石は消える |
| 囲碁 | 2 | 盤にある間、隣の相手の石が囲まれて逃げ場をなくしたら取る |
| 重力 | 2 | いつでも下へ落ちる。下に続く石も一緒に押して落とす |
| 反重力 | 2 | いつでも上へ昇る。上に続く石も一緒に押して昇らせる |
| 石垣 | 2 | 上下左右の空きマスに、誰のものでもない石を置く |
| おじゃま | 2 | まわり8マスの碁石の超能力を消して、ただの石にする |
| 地雷 | 2 | まわり8マスに相手が石を置いたら、その石と一緒に消える |
| 重し | 2 | 押し出し・吸い込み・回転で動かされない |
| 盾 | 2 | 爆弾・囲碁・地雷・乗っ取りで消されない |
| 吸い込み | 3 | 2マス先の石を1マス手前まで吸い寄せる |
| 時限爆弾 | 3 | 2手あとに爆発して、まわりの石と一緒に消える |
| 横爆弾 | 3 | 左右2マスずつの石を消す |
| 縦爆弾 | 3 | 上下2マスずつの石を消す |
| 旗 | 3 | 上下左右の4マスが全部自分の石になったら勝ち |
| 回転 | 3 | まわりの8マスを、時計回りに1つずらす |
| 逆回転 | 3 | まわりの8マスを、反時計回りに1つずらす |
| ワープ | 3 | まわり3×3の石を、盤の真ん中をはさんだ反対側へ飛ばす。飛んだ先の石は消える |
| 分身 | 3 | 盤の真ん中をはさんだ反対側にも、自分の石が1つ増える |
| 左右分身 | 3 | 左右に折り返した位置にも、自分の石が1つ増える |
| 上下分身 | 3 | 上下に折り返した位置にも、自分の石が1つ増える |
| 封印 | 3 | 相手は次の番、超能力が使えない |
| スパイ | 3 | 相手の色で置く。この石を含む列が揃ったら、こっちの勝ち。相手があと1つで揃う場所には置けない |
| 爆弾 | 4 | まわりの石を全部消す |
| ななめ爆弾 | 4 | ななめ4方向に2マスずつの石を消す |
| 増殖 | 4 | 盤にある間、自分の番が2回来るたびに、隣の空きマスに石が1つ増える |
| 連続 | 4 | もう1回置ける。続けて連続は置けない |
| スナイパー | 4 | 置いたあと、盤のどこかの石を1つ選んで消す |
| 乗っ取り | 4 | 相手の石の上に置ける。下の石は消える |
| オセロ | 5 | 相手の石をちょうど1個はさんだら、その石を自分の色にする |
| 核 | 6 | まわり5×5の石を全部消す |

超能力を足すときは、`script.js` の `ABILITIES` に1件、`ICONS` にアイコンを1件足す。

## 1手の中の順番
能力の効果 → 重力・反重力で落ちる → 囲碁と地雷で取る →（何も変わらなくなるまで、重力と囲碁をくり返す）→ 勝ち判定

## 演出
`fx.js`。碁石ごとに属性（炎・風・渦・重力・大地・水面・呪い・影・雷・植物・光・反転）を決め、置いた瞬間に、その属性の粒を Canvas で出す。盤を一瞬その色で暗くし、白い閃光と衝撃波のあとに粒が広がる。デッキの画面では、碁石にマウスを乗せると、5×5 のお試しの盤で動きを実演する。

## 効果音
`sound.js`。音のファイルは使わず、Web Audio でその場でつくる。右上のボタンで消せる。

## オンライン対戦
`net.js`。[Trystero](https://github.com/dmotz/trystero)（サーバーなしの WebRTC）でつなぐ。相手さがしは Nostr の公開ネットワークを使い、直接つながらない回線のために TURN（Metered の無料プラン。`net.js` に鍵を入れる）を保険にする。サーバーを持たないので、静的なページ（GitHub Pages など）に置くだけで動く。
- 相手さがし：ロビーにいる人を ID の順に並べ、自分より ID が大きい空いている人だけを誘う。決まったら2人だけの部屋に移る
- 同じ流れにする：おたがいのデッキを送り合い、誘った側（ホスト）が乱数の種と色を決めて送る。あとは「どの碁石をどこに置いたか」だけを送り、両方で同じ計算をする
- 通信のつなぎ方を替えるときは `net.js` だけを書き換える

## CPU
`ai.js` が CPU の頭脳。ゲームの CPU 対戦と、バランスの計測の両方で使う。
- 打つ手：minimax で2手先まで読む。自分の手を全部試し、良さそうな上位8手について、相手のいちばん良い返し手まで読んで比べる。手札は公開なので、相手の次の手札も分かる
- デッキ：スターターデッキからくじで選ぶ

## バランスの計測
`node tools/balance.mjs 3000 --depth 2` で、CPU 同士を3000局対戦させ、能力ごとの勝率を `tools/balance-report.md` に書き出す。コアの数だけ並列に動く（mameta の32スレッドで49秒）。測れるのは CPU が使ったときの強さなので、最後は人が遊んで確かめる。

HTML / CSS / JavaScript だけで作っている。`index.html` をブラウザで開けば動く。
